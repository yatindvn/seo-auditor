# Phase 2: Provider layer + Rank Tracker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Track project keywords daily through a swappable SERP provider (DataForSEO, Google CSE, dry-run) behind a persistent spend cap, store history with competitor positions, and alert on drops via Slack and email.

**Architecture:** `app/providers/` defines `SerpProvider` and its adapters, a DB-backed `SpendGuard`, and a registry that refuses to go live without `SERP_DRY_RUN=false`. `app/rank/tracker.py` turns one SERP into my position plus competitor positions per keyword. `app/alerts/` evaluates changes with pure rules, de-duplicates through a unique `alerts` row, and sends one digest per channel. The scheduler claims due projects and runs them only with a live provider. In-audit rank checks share the same CSE implementation and spend guard.

**Tech Stack:** SQLAlchemy 2.1 + Alembic, requests, smtplib, FastAPI, APScheduler, pytest.

**Spec:** `docs/superpowers/specs/2026-10-25-rank-tracker-design.md`

## Global Constraints

- Branch `feat/rank-tracker`. Baseline: backend 381 passed + 1 skipped. Frontend 57.
- **No test touches the network.** Every provider and notifier is faked or mocked.
- **Dry-run never reaches an audit or history.** Audits treat a dry-run provider as "not configured". Scheduled runs skip when only dry-run is available. Manual dry runs return an unsaved preview.
- **Registry:** `SERP_PROVIDER=dataforseo` stays dry-run unless `SERP_DRY_RUN` is exactly `false`.
- **Spend caps:** `SERP_DAILY_CAP` (default 50) caps DataForSEO; `GOOGLE_CSE_DAILY_QUOTA` (default 100) caps CSE. Usage is counted in `provider_usage` per provider per UTC day, and a unit is never refunded.
- **Never log credentials:** no DataForSEO auth, CSE key or SMTP password in any log line or exception message we create.
- DataForSEO API facts (verified 2026-10-25 from docs.dataforseo.com):
  - `POST https://api.dataforseo.com/v3/serp/google/organic/live/advanced`, with Basic auth `login:password`.
  - The body is a JSON array of task objects with `keyword`, `location_name`, `language_code`, `device` (`desktop`/`mobile`) and `depth` (max 200).
  - Success is `status_code == 20000` at both response and task level.
  - Results are in `tasks[0].result[0].items[]`, where organic items have `type: "organic"` and `rank_group`, `url`, `domain` and `title`.
- Run the full backend suite before every commit. Commit messages end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

```python
"""The SERP provider interface: one search in, ranked organic results out."""

from __future__ import annotations

import urllib.parse as up
from dataclasses import dataclass, field
from typing import List, Optional, Protocol


@dataclass(frozen=True)
class SerpQuery:
    keyword: str
    country: str = "US"
    language: str = "en"
    device: str = "desktop"
    depth: int = 100


@dataclass(frozen=True)
class SerpItem:
    position: int
    url: str
    domain: str
    title: str = ""


@dataclass
class SerpResult:
    items: List[SerpItem] = field(default_factory=list)
    provider: str = ""
    note: Optional[str] = None


class SerpProvider(Protocol):
    name: str

    def search(self, query: SerpQuery) -> SerpResult: ...


class ProviderSkipped(Exception):
    """No call was made -- not configured, or the daily cap was reached."""


class ProviderError(Exception):
    """The provider was called and failed."""


def domain_of(url: str) -> str:
    host = (up.urlsplit(url if "://" in url else "https://" + url).hostname or "").lower()
    return host[4:] if host.startswith("www.") else host
```

`app/providers/dry_run.py`:

```python
"""A provider that never touches the network. Its results are made up -- they
are for previews and wiring checks, never for audits or rank history."""

from __future__ import annotations

import hashlib
from typing import List, Optional

from app.providers.serp import SerpItem, SerpQuery, SerpResult


class DryRunProvider:
    name = "dry_run"

    def __init__(self, items: Optional[List[SerpItem]] = None) -> None:
        self._items = items

    def search(self, query: SerpQuery) -> SerpResult:
        if self._items is not None:
            return SerpResult(items=list(self._items), provider=self.name, note="dry run")
        seed = int(hashlib.sha256(query.keyword.encode("utf-8")).hexdigest(), 16)
        slug = "-".join(query.keyword.lower().split())
        items = [
            SerpItem(position=i, url=f"https://site{(seed >> i) % 50}.example/{slug}",
                     domain=f"site{(seed >> i) % 50}.example", title=f"{query.keyword} #{i}")
            for i in range(1, 11)
        ]
        return SerpResult(items=items, provider=self.name, note="dry run")
```

`app/providers/dataforseo.py`:

```python
"""DataForSEO Google organic SERP (Live Advanced).

Request and response shape per docs.dataforseo.com, checked 2026-10-25:
POST a JSON array of tasks with HTTP basic auth; success is status_code 20000
at the response and task level; organic results are the items whose type is
"organic", ranked by rank_group.
"""

from __future__ import annotations

from typing import Dict

import requests

from app.providers.serp import ProviderError, SerpItem, SerpQuery, SerpResult, domain_of

ENDPOINT = "https://api.dataforseo.com/v3/serp/google/organic/live/advanced"
MAX_DEPTH = 200
OK = 20000

# ISO 3166-1 alpha-2 -> DataForSEO location_name. Extend as projects need.
LOCATIONS: Dict[str, str] = {
    "US": "United States", "GB": "United Kingdom", "IN": "India", "CA": "Canada",
    "AU": "Australia", "IE": "Ireland", "NZ": "New Zealand", "ZA": "South Africa",
    "SG": "Singapore", "AE": "United Arab Emirates", "DE": "Germany", "FR": "France",
    "ES": "Spain", "IT": "Italy", "NL": "Netherlands", "BR": "Brazil", "MX": "Mexico",
    "JP": "Japan",
}


class DataForSeoProvider:
    name = "dataforseo"

    def __init__(self, login: str, password: str, http=requests) -> None:
        self._auth = (login, password)
        self._http = http

    def search(self, query: SerpQuery) -> SerpResult:
        location = LOCATIONS.get(query.country.upper())
        if location is None:
            raise ValueError(f"no DataForSEO location mapped for country {query.country!r}")
        task = {
            "keyword": query.keyword,
            "location_name": location,
            "language_code": query.language,
            "device": query.device,
            "depth": max(1, min(query.depth, MAX_DEPTH)),
        }
        response = self._http.post(ENDPOINT, json=[task], auth=self._auth, timeout=60)
        try:
            data = response.json()
        except ValueError:
            raise ProviderError(f"DataForSEO returned HTTP {response.status_code} without JSON")

        if data.get("status_code") != OK:
            raise ProviderError(f"DataForSEO {data.get('status_code')}: {data.get('status_message')}")
        tasks = data.get("tasks") or []
        if not tasks or tasks[0].get("status_code") != OK:
            first = tasks[0] if tasks else {}
            raise ProviderError(f"DataForSEO task {first.get('status_code')}: {first.get('status_message')}")

        results = tasks[0].get("result") or []
        raw = (results[0].get("items") or []) if results else []
        items = sorted(
            (SerpItem(position=int(i["rank_group"]), url=i["url"],
                      domain=domain_of(i["url"]), title=i.get("title") or "")
             for i in raw if i.get("type") == "organic" and i.get("url") and i.get("rank_group")),
            key=lambda item: item.position,
        )
        return SerpResult(items=items, provider=self.name)
```

```python
"""The spend guard: a hard daily cap on provider calls, counted in the DB so it
survives restarts and holds across threads and processes."""

from __future__ import annotations

from datetime import date
from typing import Optional

from sqlalchemy import select, update
from sqlalchemy.exc import IntegrityError

from app.db.engine import get_session_factory
from app.db.models import ProviderUsage, utcnow
from app.providers.serp import ProviderSkipped, SerpQuery, SerpResult


def reserve(provider_name: str, cap: int, factory=None, today: Optional[date] = None) -> None:
    """Take one unit of today's budget, or raise ProviderSkipped. A unit is
    never refunded: a call that errored may still have been billed."""
    factory = factory or get_session_factory()
    day = today or utcnow().date()
    with factory.begin() as session:
        if session.scalar(select(ProviderUsage.id).where(
            ProviderUsage.provider == provider_name, ProviderUsage.day == day,
        )) is None:
            try:
                with session.begin_nested():
                    session.add(ProviderUsage(provider=provider_name, day=day, calls=0))
            except IntegrityError:
                pass  # another caller created today's row first
        claimed = session.execute(
            update(ProviderUsage)
            .where(ProviderUsage.provider == provider_name, ProviderUsage.day == day,
                   ProviderUsage.calls < cap)
            .values(calls=ProviderUsage.calls + 1)
        ).rowcount
    if claimed != 1:
        raise ProviderSkipped(f"daily cap of {cap} {provider_name} calls reached")


class SpendGuard:
    def __init__(self, provider, cap: int) -> None:
        self.provider = provider
        self.cap = cap
        self.name = provider.name

    def search(self, query: SerpQuery) -> SerpResult:
        reserve(self.name, self.cap)
        return self.provider.search(query)
```

```python
class _RankCheckState:
    """Per-process cache of CSE results. The daily quota lives in the database
    (app/providers/spend.py) so it survives restarts and is shared with the
    rank tracker."""

    def __init__(self) -> None:
        self._cache: Dict[Tuple[str, str], Dict] = {}

    def get_cached(self, key: Tuple[str, str], ttl_hours: int) -> Optional[List[str]]:
        entry = self._cache.get(key)
        if not entry:
            return None
        if datetime.now(timezone.utc) - entry["cached_at"] > timedelta(hours=ttl_hours):

        return entry["urls"]
```

```python
"""Check a project's keywords: one SERP per keyword gives my position, the URL
that ranks, and every competitor's position."""

from __future__ import annotations

import logging
from dataclasses import dataclass, field
from datetime import datetime
from typing import List, Optional, Sequence, Tuple

from sqlalchemy import select

from app.config import config
from app.db.engine import get_session_factory
from app.db.models import Competitor, Keyword, Project, RankCheck, utcnow
from app.providers.serp import ProviderSkipped, SerpItem, SerpQuery

logger = logging.getLogger("seo_auditor")
SERP_SNAPSHOT_LIMIT = 100


def _matches(domain: str, target: str) -> bool:
    return domain == target or domain.endswith("." + target)


def position_for(items: Sequence[SerpItem], domain: str) -> Tuple[Optional[int], Optional[str]]:
    for item in items:
        if _matches(item.domain, domain):
            return item.position, item.url
    return None, None


def check_keyword(session, provider, keyword: Keyword, project_domain: str,
                  competitor_domains: List[str], depth: int) -> RankCheck:
    query = SerpQuery(keyword.phrase, country=keyword.country or "US",
                      language=keyword.language or "en", device=keyword.device or "desktop",
                      depth=depth)
    check = RankCheck(keyword_id=keyword.id, audit_id=None, checked_at=utcnow(),
                      provider=provider.name, status="skipped")
    try:
        result = provider.search(query)
    except ProviderSkipped as exc:
        check.note = str(exc)
    except Exception as exc:
        # Type only: provider exceptions may carry request details.
        logger.error("Rank check failed for %r: %s", keyword.phrase, type(exc).__name__)
        check.note = f"provider error: {type(exc).__name__}"
    else:
        position, url = position_for(result.items, project_domain)
        check.status = "ranked" if position else "not_ranked"
        check.position, check.ranking_url, check.note = position, url, result.note
        check.competitor_positions_json = {d: position_for(result.items, d)[0] for d in competitor_domains}
        check.serp_json = [{"position": i.position, "url": i.url, "domain": i.domain}
                           for i in result.items[:SERP_SNAPSHOT_LIMIT]]
    session.add(check)
    session.flush()
    return check


def previous_real_check(session, keyword_id: int, before_id: int) -> Optional[RankCheck]:
    return session.scalar(
        select(RankCheck).where(RankCheck.keyword_id == keyword_id, RankCheck.id < before_id,
                                RankCheck.status != "skipped")
        .order_by(RankCheck.id.desc()).limit(1)
    )


@dataclass
class RunReport:
    checked: int = 0
    skipped: int = 0
    changes: List = field(default_factory=list)


def run_project(project_id: int, now: Optional[datetime] = None, provider=None,
                notifiers=None, factory=None) -> RunReport:
    if provider is None:
        from app.providers.registry import get_serp_provider
        provider = get_serp_provider()
    factory = factory or get_session_factory()
    report = RunReport()

    with factory.begin() as session:
        project = session.get(Project, project_id)
        if project is None:
            return report
        competitors = list(session.scalars(
            select(Competitor.domain).where(Competitor.project_id == project_id)).all())
        keywords = session.scalars(
            select(Keyword).where(Keyword.project_id == project_id, Keyword.enabled.is_(True))
            .order_by(Keyword.id)).all()
        for keyword in keywords:
            check = check_keyword(session, provider, keyword, project.domain, competitors, config.RANK_DEPTH)
            report.checked += 1
            if check.status == "skipped":
                report.skipped += 1
    return report
```

```python
"""What counts as an alert-worthy rank change. Pure: no DB, no network."""

from __future__ import annotations

from dataclasses import dataclass
from typing import List, Optional

DEFAULTS = {"drop_threshold": 3, "top10_alerts": True, "gain_threshold": None}


@dataclass(frozen=True)
class Change:
    kind: str
    keyword_id: int
    rank_check_id: int
    phrase: str
    country: Optional[str]
    device: Optional[str]
    old_position: Optional[int]
    new_position: Optional[int]
    ranking_url: Optional[str]


def evaluate(previous, current, keyword, settings: Optional[dict]) -> List[Change]:
    """`previous` must already be the last non-skipped check. A skipped
    `current` says nothing about rank, so it never alerts."""
    if previous is None or current.status == "skipped":
        return []
    s = {**DEFAULTS, **(settings or {})}
    old, new = previous.position, current.position
    kinds = []
    if old is not None and new is None:
        kinds.append("lost")
    if old is not None and new is not None and new - old >= s["drop_threshold"]:
        kinds.append("drop")
    if s["top10_alerts"] and old is not None and old <= 10 and (new is None or new > 10):
        kinds.append("left_top10")
    if s["gain_threshold"] and old is not None and new is not None and old - new >= s["gain_threshold"]:
        kinds.append("gain")
    return [
        Change(kind=k, keyword_id=keyword.id, rank_check_id=current.id, phrase=keyword.phrase,
               country=keyword.country, device=keyword.device, old_position=old,
               new_position=new, ranking_url=current.ranking_url)
        for k in kinds
    ]
```

```python
"""One readable message per project run."""

from __future__ import annotations

from typing import List, Tuple

LABELS = {"drop": "dropped", "lost": "no longer ranks", "left_top10": "left the top 10", "gain": "improved"}


def _pos(value) -> str:
    return str(value) if value is not None else "not ranked"


def format_digest(domain: str, changes: List) -> Tuple[str, str]:
    keywords = {c.keyword_id for c in changes}
    subject = f"Rank changes for {domain}: {len(keywords)} keyword(s)"
    lines = []
    for c in sorted(changes, key=lambda c: (c.phrase, c.kind)):
        where = f"{c.country or 'US'}/{c.device or 'desktop'}"
        url = f" — {c.ranking_url}" if c.ranking_url else ""
        lines.append(f"- {c.phrase} [{where}]: {_pos(c.old_position)} → {_pos(c.new_position)} "
                     f"({LABELS.get(c.kind, c.kind)}){url}")
    return subject, "\n".join(lines)
```

```python
from __future__ import annotations

import smtplib
from email.message import EmailMessage
from typing import List

import requests

from app.config import config


class SlackNotifier:
    channel = "slack"

    def __init__(self, webhook_url: str) -> None:
        self._url = webhook_url

    def send(self, subject: str, text: str) -> None:
        requests.post(self._url, json={"text": f"*{subject}*\n{text}"}, timeout=10).raise_for_status()


class EmailNotifier:
    channel = "email"

    def __init__(self, host, port, user, password, sender, recipients: List[str]) -> None:
        self._host, self._port = host, port
        self._user, self._password = user, password
        self._sender, self._recipients = sender, recipients

    def send(self, subject: str, text: str) -> None:
        msg = EmailMessage()
        msg["Subject"], msg["From"], msg["To"] = subject, self._sender, ", ".join(self._recipients)
        msg.set_content(text)
        with smtplib.SMTP(self._host, self._port, timeout=20) as smtp:
            smtp.starttls()
            if self._user:
                smtp.login(self._user, self._password)
            smtp.send_message(msg)


def configured_notifiers(cfg=config) -> list:
    found = []
    if cfg.SLACK_WEBHOOK_URL:
        found.append(SlackNotifier(cfg.SLACK_WEBHOOK_URL))
    if cfg.SMTP_HOST and cfg.ALERT_EMAIL_FROM and cfg.ALERT_EMAIL_TO:
        found.append(EmailNotifier(cfg.SMTP_HOST, cfg.SMTP_PORT, cfg.SMTP_USER,
                                   cfg.SMTP_PASSWORD, cfg.ALERT_EMAIL_FROM, cfg.ALERT_EMAIL_TO))
    return found
```

`app/alerts/delivery.py`:

```python
"""Send each change once per channel. The alerts row is written before the
send, so the unique (rank_check, kind, channel) constraint is what stops a
repeated run from alerting twice."""

from __future__ import annotations

import logging
from dataclasses import asdict
from datetime import datetime
from typing import Dict, List

from sqlalchemy.exc import IntegrityError

from app.alerts.digest import format_digest
from app.db.models import Alert

logger = logging.getLogger("seo_auditor")


def deliver(factory, project_id: int, domain: str, changes: List, notifiers: List,
            now: datetime) -> Dict[str, int]:
    sent: Dict[str, int] = {}
    for notifier in notifiers:
        fresh, row_ids = [], []
        with factory.begin() as session:
            for change in changes:
                try:
                    with session.begin_nested():
                        row = Alert(project_id=project_id, keyword_id=change.keyword_id,
                                    rank_check_id=change.rank_check_id, kind=change.kind,
                                    channel=notifier.channel, sent_at=now, payload_json=asdict(change))
                        session.add(row)
                        session.flush()
                    fresh.append(change)
                    row_ids.append(row.id)
                except IntegrityError:
                    pass  # already alerted on this channel
        if not fresh:
            sent[notifier.channel] = 0
            continue
        subject, text = format_digest(domain, fresh)
        try:
            notifier.send(subject, text)
            sent[notifier.channel] = 1
        except Exception as exc:
            logger.error("Alert via %s failed: %s", notifier.channel, type(exc).__name__)
            sent[notifier.channel] = 0
            with factory.begin() as session:
                for row_id in row_ids:
                    row = session.get(Alert, row_id)
                    row.payload_json = {**row.payload_json, "error": _error_detail(exc)}
    return sent


def _error_detail(exc: Exception) -> str:
    """What to keep about a failed send. A requests error's message contains
    the URL -- for Slack, the webhook URL is the secret -- so only its type and
    status are kept."""
    if isinstance(exc, requests.RequestException):
        status = getattr(getattr(exc, "response", None), "status_code", None)
        return f"{type(exc).__name__} (status {status})"
    return f"{type(exc).__name__}: {exc}"
```

```python
def claim(session, project_id: int, previous: Optional[datetime], now: datetime,
          column=None) -> bool:
    """Atomically mark the project as run at `now` -- only if nobody else has
    since `previous`. `column` is the timestamp being claimed."""
    column = column if column is not None else Project.last_scheduled_at
    condition = column.is_(None) if previous is None else column == previous
    result = session.execute(
        update(Project).where(Project.id == project_id, condition).values({column.key: now})
    )
    session.commit()
    return result.rowcount == 1
```

```python
"""Rank tracking over HTTP: keywords, competitors, history, manual runs."""

from __future__ import annotations

from datetime import timedelta
from typing import List, Literal, Optional

from fastapi import APIRouter, BackgroundTasks, HTTPException, Query, Response
from pydantic import BaseModel, Field
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError

from app.api.projects import _factory
from app.db.models import Competitor, Keyword, Project, RankCheck, as_utc, utcnow
from app.db.projects import project_domain
from app.providers import registry
from app.providers.dry_run import DryRunProvider
from app.providers.serp import ProviderSkipped, SerpQuery
from app.rank import tracker

router = APIRouter()


class KeywordIn(BaseModel):
    phrase: str = Field(min_length=1, max_length=255)
    country: str = Field("US", min_length=2, max_length=2)
    language: str = Field("en", min_length=2, max_length=8)
    device: Literal["desktop", "mobile"] = "desktop"


class KeywordsIn(BaseModel):
    keywords: List[KeywordIn] = Field(min_length=1, max_length=500)


class KeywordPatch(BaseModel):
    enabled: bool


class CompetitorIn(BaseModel):
    domain: str


def _project_or_404(session, project_id: int) -> Project:
    project = session.get(Project, project_id)
    if project is None:
        raise HTTPException(status_code=404, detail="no such project")
    return project


def _check_json(check: Optional[RankCheck]):
    if check is None:
        return None
    return {"position": check.position, "ranking_url": check.ranking_url, "status": check.status,
            "checked_at": as_utc(check.checked_at).isoformat(), "note": check.note,
            "competitor_positions": check.competitor_positions_json or {}}


@router.post("/projects/{project_id}/keywords")
def add_keywords(project_id: int, body: KeywordsIn):
    created = skipped = 0
    with _factory().begin() as session:
        project = _project_or_404(session, project_id)
        for item in body.keywords:
            phrase = " ".join(item.phrase.lower().split())
            country, device = item.country.upper(), item.device
            exists = session.scalar(select(Keyword.id).where(
                Keyword.project_id == project_id, Keyword.phrase == phrase,
                Keyword.country == country, Keyword.device == device))
            if exists:
                skipped += 1
                continue
            session.add(Keyword(project_id=project_id, phrase=phrase, country=country,
                                device=device, language=item.language.lower()))
            session.flush()
            created += 1
        if created and project.rank_schedule is None:
            project.rank_schedule = "daily"
    return {"created": created, "skipped": skipped}


@router.get("/projects/{project_id}/keywords")
def list_keywords(project_id: int):
    with _factory()() as session:
        _project_or_404(session, project_id)
        items = []
        for kw in session.scalars(select(Keyword).where(Keyword.project_id == project_id)
                                  .order_by(Keyword.phrase, Keyword.id)):
            latest = session.scalar(select(RankCheck).where(RankCheck.keyword_id == kw.id)
                                    .order_by(RankCheck.id.desc()).limit(1))
            previous = tracker.previous_real_check(session, kw.id, latest.id) if latest else None
            change = None
            if latest and previous and latest.position is not None and previous.position is not None:
                change = previous.position - latest.position     # positive = improved
            items.append({"id": kw.id, "phrase": kw.phrase, "country": kw.country or "US",
                          "device": kw.device or "desktop", "language": kw.language,
                          "enabled": kw.enabled, "latest": _check_json(latest), "change": change})
        return {"items": items}


@router.patch("/keywords/{keyword_id}")
def update_keyword(keyword_id: int, body: KeywordPatch):
    with _factory().begin() as session:
        kw = session.get(Keyword, keyword_id)
        if kw is None:
            raise HTTPException(status_code=404, detail="no such keyword")
        kw.enabled = body.enabled
        return {"id": kw.id, "enabled": kw.enabled}


@router.delete("/keywords/{keyword_id}", status_code=204)
def delete_keyword(keyword_id: int):
    with _factory().begin() as session:
        kw = session.get(Keyword, keyword_id)
        if kw is None:
            raise HTTPException(status_code=404, detail="no such keyword")
        session.query(RankCheck).filter(RankCheck.keyword_id == keyword_id).delete()
        session.delete(kw)
    return Response(status_code=204)


@router.get("/keywords/{keyword_id}/history")
def keyword_history(keyword_id: int, days: int = Query(90, ge=1, le=730)):
    with _factory()() as session:
        if session.get(Keyword, keyword_id) is None:
            raise HTTPException(status_code=404, detail="no such keyword")
        since = utcnow() - timedelta(days=days)
        checks = session.scalars(select(RankCheck).where(RankCheck.keyword_id == keyword_id,
                                                         RankCheck.checked_at >= since)
                                 .order_by(RankCheck.checked_at, RankCheck.id)).all()
        return {"items": [_check_json(c) for c in checks]}


@router.get("/projects/{project_id}/competitors")
def list_competitors(project_id: int):
    with _factory()() as session:
        _project_or_404(session, project_id)
        rows = session.scalars(select(Competitor).where(Competitor.project_id == project_id)
                               .order_by(Competitor.domain)).all()
        return {"items": [{"id": c.id, "domain": c.domain} for c in rows]}


@router.post("/projects/{project_id}/competitors", status_code=201)
def add_competitor(project_id: int, body: CompetitorIn):
    domain = project_domain(body.domain)
    try:
        with _factory().begin() as session:
            _project_or_404(session, project_id)
            competitor = Competitor(project_id=project_id, domain=domain)
            session.add(competitor)
            session.flush()
            return {"id": competitor.id, "domain": competitor.domain}
    except IntegrityError:
        raise HTTPException(status_code=409, detail=f"{domain} is already a competitor")


@router.delete("/projects/{project_id}/competitors/{competitor_id}", status_code=204)
def delete_competitor(project_id: int, competitor_id: int):
    with _factory().begin() as session:
        competitor = session.get(Competitor, competitor_id)
        if competitor is None or competitor.project_id != project_id:
            raise HTTPException(status_code=404, detail="no such competitor")
        session.delete(competitor)
    return Response(status_code=204)


@router.post("/projects/{project_id}/rank-checks/run")
def run_rank_checks(project_id: int, background_tasks: BackgroundTasks, dry_run: bool = True):
    if dry_run:
        # A preview: made-up positions from the dry-run provider. Never stored,
        # never alerted on.
        provider = DryRunProvider()
        with _factory()() as session:
            project = _project_or_404(session, project_id)
            competitors = list(session.scalars(select(Competitor.domain)
                                               .where(Competitor.project_id == project_id)))
            results = []
            for kw in session.scalars(select(Keyword).where(Keyword.project_id == project_id,
                                                            Keyword.enabled.is_(True)).limit(50)):
                serp = provider.search(SerpQuery(kw.phrase, country=kw.country or "US",
                                                 device=kw.device or "desktop"))
                position, url = tracker.position_for(serp.items, project.domain)
                results.append({"phrase": kw.phrase, "position": position, "ranking_url": url,
                                "competitor_positions": {d: tracker.position_for(serp.items, d)[0]
                                                         for d in competitors}})
        return {"dry_run": True, "results": results}

    try:
        provider = registry.get_serp_provider()
    except ProviderSkipped as exc:
        raise HTTPException(status_code=409, detail=str(exc))
    if not registry.is_live(provider):
        raise HTTPException(status_code=409,
                            detail="no live SERP provider: set SERP_PROVIDER (and SERP_DRY_RUN=false for paid providers)")
    with _factory()() as session:
        _project_or_404(session, project_id)
    background_tasks.add_task(tracker.run_project, project_id, provider=provider)
    return {"dry_run": False, "status": "accepted"}
```
